# Mapeo de diseño a rutas

## Publico

- `p_gina_de_inicio_bilwi_noticias` -> `/`
- `detalle_de_noticia_bilwi_noticias` -> `/noticias/[slug]`
- `contacto_y_nosotros_bilwi_noticias` -> `/nosotros` y `/contacto`
- `iniciar_sesi_n_bilwi_noticias` -> `/login`
- `registro_de_usuario_bilwi_noticias` -> `/registro`
- `sugerir_una_noticia_bilwi_noticias` -> `/contacto` o `/sugerir-noticia`

## Administracion

- `panel_administrativo_bilwi_noticias` -> `/admin`
- `bilwi_noticias_web_admin_portal` -> `/admin/noticias`
- `coastal_editorial_system` -> sistema visual transversal para todo el sitio

## Uso recomendado

1. La portada se usa como referencia de jerarquia editorial.
2. El detalle de noticia se usa para lectura larga y relacion de contenido.
3. Login y admin se usan para la experiencia de editores y redaccion.
4. El sistema de colores y tipografia debe mantenerse consistente en todas las rutas.
